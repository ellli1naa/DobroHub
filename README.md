# DobroHub 

**DobroHub** — це інноваційна платформа (мобільний застосунок та веб-портал) для координації волонтерів та швидкого надання допомоги вразливим категоріям населення. 

## Мета проєкту
Забезпечити швидке з'єднання волонтерів із громадськими організаціями та людьми, які потребують допомоги, використовуючи систему смарт-метчингу на основі геолокації та компетенцій.

## Ключові можливості
* **Смарт-метчинг:** автоматичний підбір волонтерських завдань за локацією користувача.
* **Інтеграція з "Дія.Підпис":** швидка авторизація та безпечна верифікація користувачів.
* **Гейміфікація:** система рейтингів та відзнак для мотивації волонтерів.
* **Єдине вікно заявок:** зручний інтерфейс подачі запитів на допомогу для літніх людей та ВПО.

## Технологічний стек
* **Frontend:** React Native / React.js
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL / Prisma ORM
* **Version Control:** Git, GitHub
